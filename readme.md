# personal cs2-config 

this config is basically for linux (in case i'm using **catchy os** rn)

## requirements
1.  gamescope (`sudo pacman -S gamescope-session-cachyos` or adjust based on your distro)
2.  steam
3.  cs2.. the game, duh
4.  open the console in cs2 by pressing backtick (`` ` ``) to setting up more

## how to install

1. Navigate to the folder:
   ```bash
   cd <your-exact-location>/Steam/steamapps/common/Counter-Strike\ Global\ Offensive/game/csgo/cfg/
   ```
   
2. Create the file:
   ```bash
   nano autoexec.cfg
   ```
   (or paste/copy? yeah up to you)
